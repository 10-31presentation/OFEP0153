# Next Train 都営浅草線

浅草線の全20駅から、次の列車と残り時間を確認する発車案内です。p5.jsで日本時間の時計を描画し、列車一覧はHTMLで表示します。

## 起動

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

http://127.0.0.1:8765/ を開いてください。JSONをfetchするため、HTMLファイルの直接起動には対応しません。

## 表示

- 駅選択：西馬込 A-01～押上 A-20。初期表示は三田 A-08です。
- 駅名・駅番号：ODPTの駅マスターにある日本語名と `odpt:stationCode` を使用します。
- 方面選択：両方面／西馬込・京急線方面／押上・京成線方面。西馬込・押上ではデータがある発車方面のみ表示します。
- 各方面最大4本を発車順に表示し、種別・行き先・発車時刻・残り時間を確認できます。
- 種別は通常のゴシック体で全文を表示。「まもなく」は点滅せず表示します。
- 土日・日本の祝日は土曜休日ダイヤを使用。午前4時より前は前営業日の深夜列車として扱います。終電後は終了メッセージを表示します。

ODPT駅時刻表に含まれない番線は推測して表示せず、方面で案内します。浅草線以外の路線の発車時刻は表示しません。

## データ取得・更新

指定の[東京都オープンデータカタログ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000018d0000000052)に含まれる[東京都交通局 駅時刻表](https://ckan.odpt.org/dataset/r_station_timetable-toei)を利用しています。

配信先は `https://api-public.odpt.org/api/v4/`。APIキーは不要です。

```sh
python3 scripts/build_asakusa_timetable.py
```

`odpt:railway=odpt.Railway:Toei.Asakusa` で浅草線全駅を取得します。種別名は `odpt:TrainType.json`、都営線内の駅名と駅番号は `odpt:Station.json` を使用。公開駅マスターに含まれない直通先の駅名のみ `data/odpt-station-names.json` で翻訳します。時刻・行き先ID・種別IDはAPIの値から変換します。

- `data/asakusa-odpt.json`：取得したAPIレスポンスと取得日時。
- `data/asakusa/index.json`：駅一覧と公式駅番号。
- `data/asakusa/A-01.json` ～ `A-20.json`：各駅の画面用データ。選択された駅のファイルだけを読みます。
- `data/holidays.json`：日本の祝日（既存の holidays-jp カレンダーを引き継ぎ）。年の追加時は更新してください。

全20駅の76時刻表（両端駅は片方向。京急の泉岳寺を取得した場合は78時刻表）の欠落、不正な時刻、未登録の駅名・種別を検証してから書き出します。取得・変換の失敗時には画面用データを上書きしません。新たな直通先が加わった場合は駅名辞書を更新してください。

保存したAPIレスポンスからの再生成と検証：

```sh
python3 scripts/build_asakusa_timetable.py --offline
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/asakusa.test.js
```

更新はスクリプトの実行時に行われます。ブラウザは生成済みJSONを読む静的構成です。取得日時を画面下部に表示します。遅延・運休・臨時変更・接続は反映しません。p5.jsとWebフォントの読み込みにはインターネット接続が必要です。

## 種別色

[京成公式の停車駅案内（京急線の凡例を含む）](https://www.keisei.co.jp/keisei/tetudou/railmap/railmap_250401.pdf)を参考に、快特＝緑、特急＝赤、急行＝青、エアポート快特・アクセス特急＝オレンジ、快速＝ピンク、通勤特急＝水色、普通＝黒系としています。RGB値は公式指定値の再現ではなく、文字コントラスト比4.5:1以上を保つよう調整した値です。

## 出典・ライセンス

データ提供：**東京都交通局・公共交通オープンデータ協議会**。[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)の駅時刻表から浅草線分を抽出し、時刻・日本語ラベルを表示用に変換しています。出典・ライセンスへのリンクは画面にも表示しています。

以前の三田駅版・田町駅版のデータとスクリプトは履歴資料として残しています。浅草線版の実行・更新には使用しません。

## 泉岳寺の京急線方面

都営の `odpt:StationTimetable` には泉岳寺の京急線方面が含まれないため、[京急電鉄 駅時刻表](https://ckan.odpt.org/dataset/keikyu__r_station_timetable)を別途使用します。京急データは公開API対象外で、配信先は `https://api-challenge.odpt.org/api/v4/` です。

ODPT開発者サイトで発行される**チャレンジ2026用アクセストークン**を環境変数 `ODPT_CHALLENGE_TOKEN`、またはプロジェクトの `.env` に設定してください。

```text
ODPT_CHALLENGE_TOKEN=取得したトークン
```

通常の更新コマンド `python3 scripts/build_asakusa_timetable.py` で、都営データに加えて京急の泉岳寺駅時刻表・駅名・種別名を取得します。トークンは取得処理内だけで使い、画面用JSONやログには含めません。`.env` と京急の取得レスポンス `data/keikyu-odpt.json` はGitの追跡対象外です。

取得後の泉岳寺は「西馬込方面」「京急線方面」「押上方面」を分けて表示します。未取得の場合、京急線方面を未取得と明示し、西馬込行きを京急線方面と表示しません。都営の列車時刻表にある泉岳寺到着時刻から、京急線への発車時刻を推測する処理はありません。

京急データには都営のCC BY 4.0とは異なる[公共交通オープンデータチャレンジ限定ライセンス](https://developer.odpt.org/challenge_license)が適用されます。開発者サイトの案内では、チャレンジ開催期間中・作品応募を前提とする利用です。画面にも京急の提供元とライセンスを別に表示します。

## ライブの走行位置

[東京都交通局 列車ロケーション情報](https://ckan.odpt.org/dataset/r_train_location-toei)の `odpt:Train` をブラウザから取得します。都営浅草線に絞った公開APIを使用し、APIキーは不要です。

「列車の位置」には選択駅の前後2駅にいる列車を表示し、「全線を表示」で浅草線内の全列車に切り替えられます。表示項目は駅・駅間、方面、種別、行き先、列車番号、配信時刻、配信されている遅延です。GPS座標や駅間の進行割合を推定する処理はありません。京急・京成など都営線外の位置は対象外です。

30秒ごとに取得し、バックグラウンドのタブでは停止します。取得は15秒でタイムアウトします。有効期限を過ぎたデータ、更新から2分を超えたデータ、不正な位置は非表示にし、取得失敗やデータの古さを表示します。取得失敗中でも、前回データが期限内なら表示を維持します。

駅名・種別名の辞書 `data/asakusa/labels.json` は時刻表更新スクリプトで生成します。発車案内の残り時間は従来どおり所定時刻から計算し、走行位置や遅延秒数から発車時刻を予測しません。ライブ位置も都営データのCC BY 4.0に基づいています。

検証：`node --test tests/*.test.js`

### 路線図表示

[JR東日本公式の走行位置画面紹介](https://media.jreast.co.jp/articles/6097)を参考に、駅を縦に並べ、左右のレーンで進行方向を分けています。図の上が西馬込、下が押上です。左の列車は西馬込・京急線方面、右は押上・京成線方面です。駅に停車中の列車は駅の行、走行中の列車は駅間の行に表示します。駅間での進行割合は推定しません。

上部の「発車案内」「列車走行位置」で表示を切り替えます。列車ボタンから行き先・位置・列車番号・配信時刻・遅延を確認できます。駅番号ボタンを押すと、その駅を選択できます。選択駅を路線図内で強調し、初回表示や駅の変更時には路線図内でその駅が見える位置へ移動します。JR東日本アプリの画像や列車アイコンは使用していません。

駅・駅間の行と列車ボタンは高さを固定し、列車がいない駅間にも枠を確保します。同じ方向の列車が同じ場所に複数いる場合は横スクロールで確認できます。定期更新では縦・横のスクロール位置を維持し、列車詳細は路線図に重ねて表示するため、開閉で路線図を押し下げません。
